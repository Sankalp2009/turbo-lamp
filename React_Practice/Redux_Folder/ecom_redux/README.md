# Mini Ecommerce app using Redux(External State Management Library)

* Implement Normal Data Rendering
* Handle State Management Using Redux
* Mock-Json Server
* Implement Protected Routes, PageNotFound(*)
* Implement Login/Logout Functionality
* Implement State persist - AUTH | Cart from store.js
* Implement Filter Functionality using checkbox Filter
* Add_to_cart | Remove_Cart | Clear_Cart features
* Implement cart_Page with item's display | price variation's based on quantity (+/-)
* implement conditionally rendered Header 
* Implement Routing

## FEATURES
* Filter 
* Login / Logout
* Manage reducer/state for different data like:
*  AuthReducer - Handling Authentication as we do using context and useReducer
*  productReducer - Handling Get request
* Manage Redux store as we manage context data
* Add to cart
* Remove cart
* clear Cart
* Manipulating total price based on quantity (+/-)
* Auth failed redirect back to login

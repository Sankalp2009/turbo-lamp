# Mini API + Auth app using Redux

## Features:-
* Implement Redux State
* API Handling using external data Fetch library (swr)
* Protected Route
* Handling Authentication and Access_token
* Conditional Login / Logout 

### Key steps
  #### Implement Redux
  * install redux and react-redux
  * create Redux Folder
    * action.jsx
    * reducer.js
    * store.js
  * Create store.js file(Global Context)
  * create reducer.js file 
## Implement Routes
  * Login
  * dashboard
  * Home
